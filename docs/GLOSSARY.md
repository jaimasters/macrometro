# GLOSSARY
- Zone: aggregated sim cell (ZoneId). - Chunk: world grid tile (ChunkCoord, lod).
- F: OD flow matrix. C: generalised cost matrix. A_i: accessibility.
- Focus region: camera radius where agents render. - Snapshot: immutable sim output for render.
- RailClass: Tram/LightRail/HeavyRail/HighSpeed/DoubleDecker line specialisation.
- Mandate: political capital (economy P1). - Load factor: line load / capacity.
