# Game loop (Jai, 2026-10-12)
- Endless sandbox. No win.
- Failure modes: overcrowding (load factor >1 sustained) or under-reliance on transit (low transit share).
- Moving to a new city is the normal reset (multi-city.md); prior city keeps running coarsely.
- Difficulty drift: repeated bad outcomes raise car dependence; city converges to LA-style sprawl where travel is near impossible (see proposals/city-agency.md).
- Visual style: abstract diagram in 3D (flat-shaded, Mini-Metro palette, extruded zones).
